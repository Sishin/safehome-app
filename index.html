Questions families ask

Still unsure? These are the most common ones.

Which phones does SafeHome work on?

Any Android phone running Android 10 or newer. It works on Samsung, Xiaomi, Vivo, Oppo, Realme, Motorola, Pixel and others.

Can my parent still use WhatsApp?

Yes. You choose which apps appear on the home screen. WhatsApp, YouTube, Camera or any other installed app can be added as a big button.

How does the scam-call protection work?

SafeHome uses Android's official call-screening feature. You choose to allow all calls, silence unknown numbers, block them, or allow only trusted contacts. If the same unknown number calls twice within 3 minutes it is let through, so a genuine urgent call isn't lost. Emergency services are never blocked.

What happens if I forget the family PIN?

During setup you get a recovery code. Use it on the PIN screen ("Forgot PIN?") to set a new PIN.

Can we go back to the normal home screen?

Yes. Open Admin Mode with your PIN and choose "Leave Parent Mode". The phone's normal launcher comes back, and nothing is uninstalled.

Is it really free?

Yes, SafeHome is free to download, with no ads and no in-app tracking.
